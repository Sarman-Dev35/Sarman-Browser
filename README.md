# Sarman Browser Demo

Sarman Browser, geliştirme aşamasında olan bir web tarayıcısı projesidir. Bu depo, tarayıcının test sürümünü indirmek isteyen kullanıcılar için hazırlanmıştır.

## ⚠️ Önemli Bilgilendirme

**Bu bir test sürümüdür.**

Sarman Browser henüz geliştirme aşamasındadır. Hatalar, eksik özellikler veya beklenmeyen davranışlar içerebilir. Önemli çalışmalarınızı kaydedin ve bu sürümü kendi sorumluluğunuzda deneyin.

## 📥 İndirme

1. Bu depodaki Sarman Browser ZIP dosyasını bulun.
2. Dosyanın üzerine tıklayın.
3. Dosya sayfasındaki **Download raw file** düğmesine basarak ZIP dosyasını indirin.

## 🛠️ Kurulum

1. İndirdiğiniz ZIP dosyasına sağ tıklayın.
2. **Tümünü ayıkla** seçeneğini kullanarak dosyaları bir klasöre çıkarın.
3. Çıkardığınız klasörde `Sarman Browser Setup.exe` veya mevcutsa `Sarman Browser.msi` dosyasını bulun.
4. Kurulum dosyasını çalıştırın ve ekrandaki talimatları izleyin.
5. Kurulum tamamlandığında Sarman Browser'ı açın.

**Güvenlik notu:** Windows bir güvenlik uyarısı gösterirse dosyanın kaynağını ve bütünlüğünü doğrulamadan devam etmeyin.

## 🐛 Hata Bildirimi

Bir sorunla karşılaşırsanız aşağıdaki bilgileri not edin:

- Karşılaştığınız sorun
- Sorunu tekrarlamak için izlediğiniz adımlar
- Varsa ekran görüntüsü
- Kullandığınız Windows sürümü

Doğrulanmış bir hata bildirme kanalı henüz belirlenmemiştir.

## 🔄 Güncellemeler

Bu depo, Sarman Browser'ın demo indirme dosyasını dağıtmak için kullanılır. Yeni sürümler yayımlandığında dosya güncellenebilir. En son sürümü indirmeden önce depo içindeki dosyanın güncel olup olmadığını kontrol edin.
