## 📥 İndirme

1. Bu depodaki Sarman Browser ZIP dosyasını bulun.
2. Dosyanın üzerine tıklayın.
3. Dosya sayfasındaki **Download raw file** düğmesine basarak ZIP dosyasını indirin.

1. İndirdiğiniz ZIP dosyasına sağ tıklayın.
2. **Tümünü ayıkla** seçeneğini kullanarak dosyaları bir klasöre çıkarın.
3. Çıkardığınız klasörde `Sarman Browser Setup.exe` veya mevcutsa `Sarman Browser.msi` dosyasını bulun.
4. Kurulum dosyasını çalıştırın ve ekrandaki talimatları izleyin.
5. Kurulum tamamlandığında Sarman Browser'ı açın.

**Güvenlik notu:** Windows bir güvenlik uyarısı gösterirse dosyanın kaynağını ve bütünlüğünü doğrulamadan devam etmeyin.

# Sarman Browser Demo

Sarman Browser is a web browser project currently under development. This repository provides the demo build for users who want to try it.

## ⚠️ Important Notice

**This is a test version.**

Sarman Browser is still under development and may contain bugs, missing features, or unexpected behavior. Save your important work before testing this version. Use it at your own discretion.

## 📥 Download

1. Find the Sarman Browser ZIP file in this repository.
2. Click the file name.
3. Select **Download raw file** to download the ZIP archive.

## 🛠️ Installation

1. Right-click the downloaded ZIP file.
2. Select **Extract All** to extract its contents into a folder.
3. Open the extracted folder and look for `Sarman Browser Setup.exe` or, if available, `Sarman Browser.msi`.
4. Run the installer and follow the on-screen instructions.
5. Once installation is complete, launch Sarman Browser.

**Security notice:** If Windows displays a security warning, verify the file's source and integrity before proceeding.

## 🐛 Reporting Issues

If you encounter a problem, please note the following information:

- What went wrong
- The steps needed to reproduce the issue
- A screenshot, if available
- Your Windows version

An official issue-reporting channel has not yet been established.

## 🔄 Updates

This repository is used to distribute the Sarman Browser demo download. The file may be updated when new versions become available. Check this repository for the latest available build before downloading.
